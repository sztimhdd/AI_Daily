## 目标

让文章配图同时服务真实信息理解与阅读表达。按内容主动寻找合适源图，并允许与生成图混搭；在三平台共享封面上先确定画面表达再选风格；有限参考近期不同文章的封面以减少相似观感。最终成果落在双语 Markdown。保留 Hobbyist MVP 边界：不设固定图片数/字数或风格轮换，不程序审核创作，不新增评分、检索或审计系统。

## 共识与当前证据

2026-10-10 本轮收尾：02/04/05 的有界结果与 03 的实际图文产物已由主控接受。890 Deep 为 3 generated / 1 source，891 无模型机械组装，892 News 为 1 generated / 1 source；六实际资产及四份双语 Markdown 已本地保存。主控已查看实际资产，确认混搭、不同画法和两张无可见字封面。News MD 是一次小资产 metadata 读取后，使用完整 fixture 与原版 Assemble/MD 代码的 replayed-from-observed-assets，不能写成原生 MD 回读。

非阻塞项保留：News 原生大响应回读未解决；个别视觉选择、位置或 Alt/Caption 仍需实际使用改进。Deep 原图是发布素材，News 原图是既有鹈鹕自行车示例图，不保证每篇取得核心实测图。新 draft `88b6ec3f-3738-42e7-82cf-e500a1355fd3`（105 节点）未激活；旧 active `96042bba-9621-4571-98b6-976dc819c4fc` 保持。native draft/active 与依赖恢复材料已私下保存，不发布、不新增测试或修复票框架。

- 图片兼具信息展示/解释与氛围、隐喻、幽默、阅读节奏。
- 默认源图与生成图混搭并主动找贴题源图，数量与组合依文章决定，Deep 不默认全生成。没有合适源图时可不含 source 并记录或收窄表达；不得生成冒充真实测试、Demo 或社区截图。
- LinkedIn、知乎、微信共用一张无字封面，不叠标题或 Caption、不裁切；既有来源及 Alt 信息保留。可选合适已有图，不强制重生。
- 内容 → 画面表达 → 风格；风格库提供用途/气氛说明，画面计划写主体、构图、配色、手法。源图保留真实内容。
- 近期参考最近三篇不同文章的实际封面图像，或从实际图像读取的可靠视觉摘要，回避相似材质、构图或颜色但不强制轮换。旧 prompt 仅辅助创作意图，不作视觉参考，也不能替代成图。双语共封面算一篇；历史不足时用已有图像；读取历史失败时保留正文并如实注明未参考。不得用 URL 或文字标签假装看过图。
- 01 已完成的共享 Planner、图片取得/生成和 Markdown 路径可复用。875 是缩减且漏掉编辑意见的无效回放输入，不作为原 856 行为证据；877 才是校正输入下的单次观察（3 generated / 0 source，未实际生图），模型内因 UNKNOWN。它不是 Deep 社区选图成功或失败的结论。

### 02 — 主动取材与混合配图

**Blocked by：** 01（已完成历史切片）。

**交付：** 一个有真实图片需求且已授权的 Deep 样本，主动取材与规划后到达双语 Markdown；默认源图与生成图混搭并主动找贴题源图。用完整真实输入观察模型是否回应作者对原图的要求，不提示必须选择哪张图，也不强制图片数或每篇必须有 source。无合适源图可不含 source 并记录或收窄表达。若有贴题 source 且作者要求仍未采用，记录原因，效果仍为未验证/未解决。工具/登录缺失则 BLOCKED；不新建视觉服务、平台配额或静默切换模型/provider/harness。
**参考与最小适配：** [Article Illustrator、qiaomu-ppt 取材方法](../../docs/research/ai-daily-visual-reference-kb-2026-10-10.md)：先找视觉机会/用途，区分 source 与解释或氛围生成图；仅将实际图片信息当作已理解。

### [04 — 三平台共享无字封面](issues/04-shared-text-free-cover.md)

**Blocked by：** 01；02 不阻塞本票。

**交付：** LinkedIn、知乎和微信按文章内容复用合适的已有源图或生成图作为同一无字封面；不叠字、不裁切，保留来源/Alt 信息，双语 Markdown 可读。仅 fresh-read 证明必要时最小扩展当前 `source-cover` 角色。失败保稿，不要求重新生成封面。
**参考与最小适配：** [Baoyu Cover Image、KarenSpinner 封面方法](../../docs/research/ai-daily-visual-reference-kb-2026-10-10.md)：由文章含义/具体对象拆为画面主体、动作关系、构图、配色和手法；保留本项目无字共享封面规则，不引入默认文字或固定角色。

### [05 — 内容驱动风格与近期封面参考](issues/05-content-driven-style-history.md)

## 验收边界

统一入口是保存稿件及可取得素材到最终双语 Markdown。检查真实图片是否实际取得/可打开、封面是否按共识共享、图注是否可读及失败时稿件是否保留。人工读图限于实际取得的图或可靠视觉摘要；不声称看过裸 URL。不得编写文章专属测试答案、强制图片数/字数、评分创作或以一次自由模型成功宣称稳定效果。
