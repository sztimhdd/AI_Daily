# Remove-AI-Slop Contract（V1 编译版，可执行）

本文件是从核心知识产权 JSON 编译出的去 AI 味检查契约。
可执行实现：`src/ai_daily/deslop.py`（8 个类别逐一检测，返回 findings）。
draft 阶段生成的文章必须通过全部 8 类检查，才算完成。

## Provenance（来源追溯）

- `workflows/reference/公众号选题写稿配图一体化工作流.json` → 节点 `去AI味`：
  MODULE 1 零容忍黑名单（大厂黑话 / 伪高级修辞 / 机翻公关废话 / AI 模板结构）、
  MODULE 2 十大转化法则、MODULE 4 技术安全锁。
- 同工作流节点 `中文图文编辑`：禁“总之 / 总而言之 / 值得注意的是 /
  这不是...而是 / 解锁 / 变革性”；删除“金句：/ 总结：/ [编辑注]”标签。

## 8 类检查（与 deslop.py 一一对应）

### 1. 空泛 AI 连接词（empty-connectives）
僵硬连接词黑名单：此外、然而、总而言之、综上所述、值得注意的是、总之。
替代：用因果与事实直接推进，必要时用“但 / 可是 / 说白了”。

### 2. 模板化开头（template-opening）
烂大街开场黑名单：随着...的飞速发展 / 在当今的数字化时代 / 众所周知 /
不可否认的是 / ...成为了热门话题。
替代：第一句直接给硬事实（News Peg）。

### 3. 机械总分总（mechanical-enumeration）
“首先 / 其次 / 最后”成对出现即判定（单独一个“最后”不算）。
替代：散点跳跃，用口语化转折连接（“但是更要命的是”“其实说白了”）。

### 4. 过度对称排比（over-parallelism）
绝对黑名单：不仅是...更是（出现 1 次即判）。
软黑名单：不是...而是 / 既...又... / 一方面...另一方面（全文累计 ≥2 次判）。
替代：拆成两句独立陈述，保留一边立场。

### 5. 过度书面化（corporate-bookish）
大厂黑话 + 伪高级修辞 + 机翻腔黑名单：
赋能、闭环、颗粒度、抓手、对齐、拉通、链路、沉淀、倒逼、耦合、解耦、
复盘、迭代、落地、组合拳、生态位、顶层设计、底层逻辑、赛道、势能、
心智、痛点、中台、熵增、熵减、降维打击、涌现、奇点、第一性原理、
飞轮效应、数据引力、长尾效应、黑天鹅、灰犀牛、认知突围、图谱、矩阵、
共生、共创、全景、蓝图、基石、催化剂、致力于、旨在、标志着、
不可或缺、至关重要、具有深远的意义。
替代：翻译成具体动作与业务结果（“实现价值闭环”→“最后能赚到钱”）。

### 6. 空泛营销词（marketing-hype）
黑名单：解锁、变革性、颠覆性、里程碑式、重磅、王炸、炸裂、沸腾、轰动。
替代：给具体数字与事实，要么不写。

### 7. 无依据确定性结论（unsupported-certainty）
黑名单：必将、必然、毫无疑问、毋庸置疑、注定、一定会、肯定会、铁定。
替代：有来源就给来源；没有就降低断言强度或标注不确定。

### 8. 僵硬结尾升华（stiff-ending-uplift）
烂尾预言黑名单：让我们拭目以待、时间会给出答案、未来可期、开启新纪元、
新篇章、让我们共同。检查范围为文章结尾段。
替代：以具体风险提示或冷酷推演收尾（冷 Kicker）。

## 技术安全锁（生成与检查都必须遵守）

1. 图片占位符（如 `{[IMG_1]}`）与 Markdown 图片链接必须原封不动保留，
   前后各保留一个空行。
2. Markdown 标题 / 加粗 / 引用结构保留；加粗前后各一个空格。
3. 检查只报告位置与命中词，不改写原文；改写由 draft 生成器负责。
