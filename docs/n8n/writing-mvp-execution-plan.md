## 产品主线

```text
每天采集 → 最多5题（不足明确说明）→ 选1题＋补充方向 → 初轮研究
→ 一次Deep适用性判断
    News：自动报道方向，无Narrative人工审批
    Deep：标题＋核心判断＋大纲，一次人工确认/修改
→ 两分支共用定向补查规划和取材
→ News Writer / Deep Writer（language参数复用，每篇中英两版）
→ 一次轻编辑 → 按模式配图 → 返回图文草稿
```

[KNOWN][HIGH] News优先真实新闻图片、产品或Demo截图、评测图和社区帖截图；Deep优先辅助叙事的AI插图和示意图，真实数据图必须基于已取得数据。没有图或生成失败仍返回完整正文。中文知乎稿、英文LinkedIn稿各有本语言标题、Caption/Alt；Kit最后补完，不构成多轮正文改写。
