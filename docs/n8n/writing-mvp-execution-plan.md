## 编辑目标：愿意点开，愿意读完，读完有所得

[INFERRED][HIGH] 面向对 AI 感兴趣的普通读者。验收先读文章，不先数检查项：标题与开头有没有具体吸引力；事件、人物选择与细节有没有持续推进；技术是否讲成人话；读完是否多明白了一件值得关心的事。没有明显错误但乏味的稿件不算完成。

[INFERRED][HIGH] 事实准确是写作底线，不是正文主题。来源归属用自然叙述和链接处理；不把“未独立验证”“证据不足”“这不是测评”逐段贴进正文。不为证明研究充分而穷举来源，不要求普通读者读长段英文原文再读翻译。影响理解的限定留在相关句子里，不另搭审计框架。

[INFERRED][HIGH] 初稿不是终审稿。已有故事和完整正文，就进入一次正常编辑：保留好段落，重排拖沓处，删掉重复解释，局部错误就地修改。只有核心故事立不住、必须补造事实才能成立时，才退回上游；不因为一句过度表述、引语排版或可局部修正的归属问题整篇重抽。

[INFERRED][HIGH] 不新增评分系统、评审 Agent 或更多关卡。当前最短路径是：已有中文初稿 → 现有中文编辑节点完成一次读者向编辑与必要局部修正 → 可阅读预览。其他语种、配图和母流程接入随后逐个验证。
