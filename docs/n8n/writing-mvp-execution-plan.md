## 写作优先级

[INFERRED][HIGH] 先判断标题和开头是否让目标读者愿意继续读，再判断故事是否持续推进、解释是否讲成人话、结尾是否带来值得记住的认识。没有明显错误却乏味的文章，不算完成。

[INFERRED][HIGH] 允许有性格、有取舍、有判断的表达。可以重排段落、合并小节、删除无趣枝节，用准确的中文转述替代长英文引语。材料服务于故事，不把每条材料都扩成段落，不把版本更新清单和核验过程直接交给读者。

[INFERRED][HIGH] 准确是底线，不是正文主题。自然归属和必要链接通常已经足够；不要反复加“未独立验证”“不能证明”等说明。局部错误直接在原句修改，不把修正写成一节论文。只有核心故事无法成立、需要编造事实才能继续时才退回研究。

[INFERRED][HIGH] 撤销“初稿必须零瑕疵才允许进入编辑”的推进方式。最短链路：完整中文初稿 → 现有中文编辑一次 → 可阅读预览。保留好段落，修具体问题，不反复整篇重抽，也不加新的评分系统或评审 Agent。

## 随后逐个推进

[INFERRED][HIGH] **其他语言/模式：** News/en-US、Deep/zh-CN、Deep/en-US 分别实际成稿。News 讲清事件，不硬塞 thesis；Deep 展开材料支持的明确判断。语言分别成文，不逐句翻译，不复制四套工作流。

[INFERRED][HIGH] **图像与发布包：** 复用既有视觉规划、编译、生成和组装。配图编辑阅读完成文字编辑后的草稿，再决定正文图片的数量、视觉类型与插入位置；生成与组装按该计划执行。图文组装不重写正文；图片或社交文案失败单独降级并保留正文。输出保持 draft/preview。
