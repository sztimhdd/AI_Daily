# Live workflow snapshots

`atomic-topic-survey-skill.json` is a sanitized source snapshot of the
published n8n version `cc92a46f-f8fd-478b-9430-d7fb6bc8f133`.

Credential IDs/names and the internal AIHOT endpoint are removed, so
the snapshot must be rebound before import. This repository artifact is
a reviewable snapshot only; the live deployment is already published.

`long-content-writing-editorial-patch.json` records the retained Narrative,
URL handoff, Writer source-input and visual-selection parameter changes for
`Long-Content-Writing`. It is a native-operation parameter patch against the
recorded prior active version, not a complete importable workflow. Models,
credentials and connections are deliberately outside this patch. See the
[release record](../../docs/operations/2026-10-15-editorial-release.md) for
deployment versions, validation and candidate decisions.
