Claude Flickers: Why AI Buyers Need an Escape Hatch

### 2. SEO Description
When one AI platform flickers, critical workflows can stall. Map dependencies, test fallbacks, and define human takeover rules before failure strikes.

### 3. LinkedIn Post

Hook: One AI platform serving every critical workflow is a concentration risk waiting to surface.

Meat:
- Map shared failure domains, alternate routes, manual checkpoints, and data boundaries before signing.
- Define incident notice, recovery objectives, evidence delivery, and human takeover triggers in contracts.
- Test fallback models with representative tasks, tool calls, latency, formatting, and escalation behavior.
- Make availability an operational permission boundary with named owners and reversible actions.

Pivot: The deeper lesson is that AI procurement should evaluate failure handling before model quality when the model touches a critical path.
