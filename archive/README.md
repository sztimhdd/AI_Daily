# Historical archive

This directory preserves material created before the Codex-native rebuild. It is read-only and excluded from current runtime assumptions.

- `legacy-content/` contains previously published articles, images, and local drafts.
- `legacy-n8n/` contains retired workflows, generated n8n assets, infrastructure, and old project documentation.
- `legacy-tools/` contains retired utilities with embedded secrets redacted.

Git history remains the source for exact pre-cleanup paths. Moving sensitive material here does not erase it from history.
